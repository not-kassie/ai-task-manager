# AI Task Manager 

A program to organize tasks, prioritize workloads, and recommends productivity improvement. 

## Project Overview 
AI Task Manager is a desktop application that helps its user base to organize their workload, prioritize certain tasks, create schedules to ensure deliverables meet their due date, and make productivity recommendations based on the user's history sourced from a locally running language model. It is attended for students, or those working with a deadline. 

**Scope:** Single-user Windows desktop application. No user accounts or cloud sync. All data and AI processing stay on the user's computer.
